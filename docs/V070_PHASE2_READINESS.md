# Phase 2 Readiness (Research / Features)

## Что Phase 2 получает
- `MarketDataStore.get_candles / last_candles` — только закрытые, отсортированные, выровненные, Decimal, UTC.
- `BackfillService.ensure_history(symbol, tf, usable_bars, lookback)` — гарантирует warmup или бросает `InsufficientHistory`.
- `Feature.timeframe` уже типизирован `Timeframe`; `FeatureSnapshot.get()` строгий.
- Единицы volume/turnover задокументированы и проверяются.

## Решения, которые нужно принять в начале Phase 2
1. **Политика дыр для индикаторов.** Сейчас `ensure_history` падает при любой дыре в окне. Нужно явно решить: пропускать символ; допустить N пропусков с пометкой фичи; или пересчитывать окно от последней дыры. Молча склеивать ряд через дыру нельзя.
2. **Мульти-таймфрейм.** Агрегировать 1h из 15m (один источник истины) или хранить каждый таймфрейм отдельно (как сейчас)? Во втором случае нужна проверка согласованности close(1h) == close(последнего 15m).
3. **CVD.** Bybit kline не содержит buy/sell-разбивки. CVD требует публичных сделок (`/v5/market/recent-trade` — только последние 1000, истории нет) или WS-потока. Без этого CVD будет приближением — такая фича должна называться честно (например, `signed_volume_proxy`).
4. **Инкрементальное обновление.** Сейчас backfill запускается вручную; для research нужен планировщик «догрузить до последнего закрытого бара».
