# Phase 8 Readiness

## Что теперь есть
Воспроизводимые датасеты, point-in-time replay существующей аналитики, outcome analysis сетапов (MAE/MFE, forward returns, censoring), изолированный backtest тест-правил с моделью издержек, метрики с явным `not_available`, хронологические выборки с purge/embargo, неизменяемое хранение результатов.

## Что нужно сделать до решений о стратегии
1. **Реальные данные.** Загрузить ≥ 2–3 месяцев 15m/1h/4h для BTC/ETH/SOL + funding, собрать датасет, выполнить replay, outcomes, backtest. Посмотреть: сколько сетапов каждого типа, их MFE/MAE, долю censored/incomplete.
2. **Выборка.** Решения — только по validation; test открывается один раз в конце. Минимальный объём наблюдений на тип сетапа до любых выводов (например, ≥ 100 valid на горизонт).
3. **Расширение модели издержек**, если будет исполнение на Bybit Demo: реальные тарифы аккаунта, округление количества, минимальный ордер.
4. **Следующий логичный этап** — Entry/Risk-слой в режиме paper (не live): правила входа строятся только на выводах validation-выборки, Risk Engine — финальный арбитр.

## Вердикт
**READY** для исследований на реальных данных. **NOT READY** для любых торговых решений до выполнения пунктов 1–2.
